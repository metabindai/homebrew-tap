# Metabind Homebrew tap

Homebrew formula for `metabind`, the Metabind command-line interface. Use it to build, validate, and publish MCP apps from a terminal or a coding agent.

## Install

```sh
brew install metabindai/tap/metabind
metabind --version
```

The formula installs prebuilt binaries for macOS on Apple silicon and Intel. There is no Linux or Windows build.

## Upgrade

```sh
brew upgrade metabind
```

`metabind update` does the same: on a Homebrew install it runs `brew upgrade metabind`.

## Get started

Installation, sign-in, and first steps: https://docs.metabind.ai/cli/install

Each release's binaries and `SHA256SUMS` are attached to this repository's [releases](https://github.com/metabindai/homebrew-tap/releases).
